# EstateFlow — Separate-page frontend

Each main area is its own HTML page:

- `index.html` / `overview.html` — dashboard
- `properties.html` — properties
- `tenants.html` — tenants
- `payments.html` — payments
- `maintenance.html` — maintenance
- `landlords.html` — landlords
- `staff.html` — staff
- `reports.html` — reports
- `settings.html` — settings

Shared assets:
- `styles.css` — responsive styling used by every page
- `app.js` — shared sample data and page interactions

Open `index.html` in your browser. Use the left navigation to move between separate HTML files.

This is a frontend demo. Records are sample data held in the browser session; a real multi-user deployment needs a backend, database, authentication and payment integration.
